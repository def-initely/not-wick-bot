# Not Wick Discord Bot

Standalone Discord bot extracted from the Replit project.

## Requirements

- Node.js 20+
- pnpm
- A Discord bot token stored as `DISCORD_BOT_TOKEN`

## Commands

- `pnpm install`
- `pnpm run build`
- `pnpm run start`

For a one-command build + start:

- `pnpm run bot`

Never commit `.env` or a real Discord token.
